Running the Examples
--------------------

To run these examples, you'll need Jupyter installed:

.. code-block:: bash

   pip install jupyter
   cd docs/examples
   jupyter notebook

The examples assume you have calibration data available. You can modify the
data paths to point to your own measurement files.
